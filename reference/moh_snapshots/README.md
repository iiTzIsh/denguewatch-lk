# MOH reference snapshots — DEMO DATA

These files are **made-up practice data** to learn SCD Type 2.
The snapshot dates (2025-01-01, 2026-01-01) and notes are NOT real — they only simulate
"Kesbewa split from Piliyandala" (the real case from the project brief).

In Phase 2 these get replaced by real snapshots built from NDCU/WER region lists,
with the real change dates verified from source.

One file = the full list of MOH areas as known on that date (file name = as-of date).
