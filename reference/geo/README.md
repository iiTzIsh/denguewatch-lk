# District boundaries

`lka_districts.geojson` - 25 districts of Sri Lanka, from **geoBoundaries gbOpen LKA ADM2** (simplified),
built from OpenStreetMap data, licensed under the **Open Data Commons Open Database License (ODbL) 1.0**.
Source: https://github.com/wmgeolab/geoBoundaries (releaseData/gbOpen/LKA/ADM2).
Changes: added `district` slug property, rounded coordinates to 4 decimals. Used only to draw the dashboard map.
